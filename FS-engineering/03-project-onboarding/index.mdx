## Project Onboarding

### What is Project Onboarding?

**Project Onboarding** covers the first decisions made on any new engagement - creating the project correctly, selecting a tech stack that fits the client's constraints, and using the right starting templates instead of a blank repository.

In simple terms: **project onboarding answers the question, "How do we start this project the right way?"**

### Who is this for?

- **Delivery Leads** scoping a new engagement
- **Engineers** setting up a new project's repository, CI/CD, and tooling for the first time
- **Architects** advising on tech stack selection

### How to navigate

This chapter has one episode - **Onboarding** - covering project creation, tech stack selection, and starter templates.
