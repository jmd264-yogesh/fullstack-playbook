## Documentation

Standards for technical documents, project documents, and handover documentation.

### Pages in this episode

| Page | What It Covers |
|---|---|
| [Technical Document](./01-technical-document) | > A Technical Document (Tech Spec) must be written before implementation begins for any feature that introduces new architecture, affects multiple services, changes a data model, or carries significant risk. |
| [Project Documents](./02-project-documents) | > These four documents must exist before feature development begins. They are not optional and must be kept up to date throughout the project lifecycle. |
| [Handover Document](./03-handover-document) | > A Handover Document is produced at the end of a project engagement or when ownership transfers from one team to another. |
